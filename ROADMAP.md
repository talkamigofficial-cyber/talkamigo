# TalkAmigo roadmap

Built in small slices; each one is checked by the founder on the iPhone before the next starts.
(Order from `docs/handoff/HANDOFF.md` §9.)

- [ ] **1. App shell (no server):** project set-up, sign-up, profile, the 5 tabs with demo data, 8 languages (Arabic right-to-left), light and dark.
- [ ] 2. Accounts and database (Supabase): real sign-in (Apple, Google, phone SMS), real profiles, follow, block, report.
- [ ] 3. Chats: 1-to-1, groups, corrections, translation; push notifications.
- [ ] 4. Connect and Flicks: real feeds, posting, comments, search.
- [ ] 5. Talk rooms, then live video, then calls (LiveKit).
- [ ] 6. Coins, gifts, Plus, boosts (Apple / Google in-app purchases through RevenueCat).
- [ ] 7. Teachers: application, approval in the admin site, paid lessons, payouts (Stripe Connect).
- [ ] 8. Admin site, moderation, legal pages, store preparation.
